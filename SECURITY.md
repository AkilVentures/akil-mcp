# Security

Akil MCP is a hosted public-records service. This repository contains public
connection metadata and documentation, not the hosted server implementation.

## Reporting a security issue

Email [hello@akilventures.com](mailto:hello@akilventures.com) with:

- a short description of the issue
- the affected endpoint or workflow
- steps to reproduce, if safe to share
- any relevant client or integration context

Please do not open a public GitHub issue for security reports.

## Sensitive information

Do not include API keys, bearer tokens, private prompts, customer data, or
sensitive documents in GitHub issues, pull requests, screenshots, or examples.

Use placeholders such as:

```text
Authorization: Bearer <AKIL_API_KEY>
```

## Bounty status

Akil does not currently operate a public bug bounty program.
